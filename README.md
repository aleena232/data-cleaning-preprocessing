# data-cleaning-preprocessing
Data cleaning and preprocessing project using Excel.
## Project Overview

This project focuses on cleaning and preprocessing a medical appointment dataset using Microsoft Excel.

The objective was to identify and handle common data quality issues and prepare the dataset for further analysis.

## Dataset

The dataset used for this project is the Medical Appointment No Shows dataset.

It contains information related to medical appointments, including patient demographics, appointment dates, health conditions, SMS reminders, and appointment outcomes.

## Tools Used

- Microsoft Excel
- GitHub

## Data Cleaning Steps

The following data cleaning steps were performed:

1. Checked the dataset structure and dimensions.
2. Checked for missing values.
3. Checked for duplicate records.
4. Standardized date formats.
5. Reviewed and standardized column names.
6. Checked data types.
7. Checked for unusual values and potential outliers.
8. Prepared the cleaned dataset for further analysis.

## Missing Values

The dataset was checked for blank cells using Excel's COUNTBLANK function.

No missing values were identified.

## Duplicate Records

The dataset was checked for duplicate records using Excel's Remove Duplicates feature.

No duplicate records were identified.

## Final Output

The cleaned dataset and cleaning documentation are included in this repository.
